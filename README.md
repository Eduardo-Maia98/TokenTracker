# TokenTracker

App Expo (React Native) para acompanhar o uso de tokens de contas de IA — MVP focado no **Cursor**.

## Setup

```bash
npm install
npx expo start
```

Rotas em `src/app/`. Domínio, data e presentation seguem `specs/architecture.md`.

## Scripts

| Comando | Uso |
| --- | --- |
| `npm start` | Dev server Expo |
| `npm test` | Jest |
| `npx expo lint` | ESLint |
| `npx tsc --noEmit` | Typecheck |
